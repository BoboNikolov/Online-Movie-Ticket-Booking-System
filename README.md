## Sprint 1 Prototype

This repository demonstrates three connected user stories:

1. Browse, search, and view movie details.
2. Select a showtime and available seats.
3. Complete a simulated payment and receive a booking confirmation.

## Run the prototype

No installation is required.

1. Open the repository folder.
2. Double-click `index.html`.
3. Search for a movie and select **View details**.
4. Choose a showtime.
5. Select seats and continue to payment.
6. Use one of the demonstration card numbers to test approval or decline.

For the most reliable browser behaviour, open the folder in Visual Studio Code and use the Live Server extension.

## Demonstration data

- Valid promo code: `SAVE10`
- Approved test card: `4242 4242 4242 4242`
- Declined test card: `4111 1111 1111 0000`

Do not enter real payment-card information. The payment process is simulated locally.
